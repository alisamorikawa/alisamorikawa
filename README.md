# Алиса Морикава · авторский блог

## Посмотреть сейчас

Откройте в браузере файл `preview/index.html` из соседней папки. Это готовая копия главной и записи. Для просмотра достаточно браузера. Ссылки на Telegram и издателя ведут в интернет.

## Указать контакты

Адрес для писем задаётся в поле `email` файла `_config.yml`. Если поле пустое, читатели видят подписанный пример. В поле `telegram` хранится имя канала без знака @.

## Добавить запись

1. Создайте в `_posts` файл UTF-8, например `2026-11-05-zametka.md`. Имя начинается с даты публикации в формате ГГГГ-ММ-ДД, за ней идут дефис и короткое название латиницей. Укажите нужную дату. Jekyll по умолчанию скрывает будущие записи.
2. Скопируйте пример. Верхний блок задаёт название и подпись для главной страницы. После второго разделителя пишите саму запись.

```markdown
---
title: "Название записи"
description: "Одно предложение для списка записей."
---

Первый абзац записи.

## Подзаголовок

Следующий абзац. Можно выделять текст **полужирным** или *курсивом*.
```

3. Сохраните файл. При сборке Jekyll создаст страницу записи и добавит ссылку в раздел «Блог». Самые новые записи будут первыми. Демонстрационную запись `_posts/2026-11-01-pervaya-zapis.md` можно удалить или заменить своей.

Названия и порядок книг редактируются в `_data/books.yml`. Обложки лежат в `assets`.

Для изображения в списке записей добавьте в верхний блок записи поля `image` и `image_alt`. В первом укажите путь от корня сайта, например `/assets/baltic-moon-thumbnail.webp`, во втором — краткое описание изображения. Записи без этих полей отображаются без миниатюры.

Коллаж первого экрана хранится в `assets/author-collage.webp`. Исходный автограф подключён отдельно из `assets/author-signature.svg`.

## Смотреть изменения локально

1. Для Windows установите Ruby с Devkit и выполните предложенную установщиком настройку MSYS2. Откройте новое окно PowerShell. [RubyInstaller](https://rubyinstaller.org/)
2. Выполните команды:

```powershell
cd E:\alisa-morikawa-website\writer-blog
gem install bundler
bundle install
bundle exec jekyll serve --host 127.0.0.1
```

3. Откройте адрес из строки `Server address` (обычно `http://127.0.0.1:4000/`). После сохранения Markdown обновите страницу. После редактирования `_config.yml` нажмите Ctrl+C и снова запустите последнюю команду. Папка `preview` содержит отдельную готовую копию для просмотра; изменения исходников Jekyll не переносятся в неё автоматически.

## GitHub Pages

Публикуемый проект находится в папке `writer-blog`. У неё свой Git-репозиторий с удалённым адресом [alisamorikawa/alisamorikawa](https://github.com/alisamorikawa/alisamorikawa). Файлы из родительской папки и статическая копия `preview` не участвуют в публикации.

При первой настройке после отправки ветки `main` откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, затем **main** и **/(root)**. Нажмите **Save**. GitHub сам соберёт Jekyll. За ходом публикации можно следить во вкладке **Actions**. Адрес сайта указан в настройках Pages. Для этого репозитория ожидается [alisamorikawa.github.io/alisamorikawa/](https://alisamorikawa.github.io/alisamorikawa/).

Для обновлений редактируйте файлы в `writer-blog`. Сохраните изменения коммитом и отправьте его в `main`. GitHub Pages запустит сборку автоматически. Новую запись также можно добавить на GitHub в папке `_posts` через **Add file → Create new file** и сохранить в `main`.

[Официальное руководство по источнику публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Локальные шрифты

Заголовки используют Cormorant Garamond (500 и 600), основной текст — Literata (400, 600 и настоящий курсив 400). Полные кириллические начертания WOFF2 и лицензии OFL находятся в assets/fonts. Шрифты загружаются с самого сайта, без обращения к Google Fonts. Относительные пути в assets/site.css работают и при размещении GitHub Pages в подпапке.

Для запуска готового превью из корня проекта: python -m http.server 4173 --directory preview. Адрес: http://127.0.0.1:4173/.
